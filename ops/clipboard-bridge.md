# Общий буфер обмена Windows ↔ удалённые машины (2026-11-15)

Двусторонний мост буфера (текст + изображения) между локальным Windows и
X-буфером удалённых машин (Xvfb :99 + xclip). Последнее изменение побеждает;
латентность ~2–4 с.

## Компоненты

- `ops/scripts/clip-bridge.py` — удалённая сторона, ставится в
  `~/.local/bin/clip-bridge` (dev: hermes, 1c: vscode). Команды:
  `get` (JSON {text,img-hash} с разбором TARGETS), `get-image` (base64 PNG),
  `set-text`, `set-image`. Запись через временный файл, чтобы fork xclip не
  держал ssh-канал.
- `ops/scripts/clip_sync.py` — Windows-сторона: опрос локального буфера
  (WinForms, UTF-8, `SetDataObject($img,$true)` для картинок — иначе
  короткоживущий powershell не успевает отрендерить данные) и удалённых
  (`ssh gbig-herdr-dev / gbig-1c-app`, без ControlMaster — Win32-OpenSSH его
  не умеет). Недоступная машина пропускается и не перетирает локальный буфер.
- Автостарт: `Startup\HerdrClipboardSync.vbs` (pythonw, без окна, при логоне).
  Остановить: убить pythonw с `clip_sync.py` в командной строке; удалить vbs
  для отключения автостарта.

## Поведение клавиш (Herdr App)

- Ctrl+V в удалённом терминале отдаётся удалённой программе; её собственный
  буфер теперь зеркало локального → Ctrl+V в DSH/TUI пастит локальное.
- Ctrl+V с картинкой в буфере App сам передаёт её файлом на удалённую машину
  (`terminal.paste_image`).
- Ctrl+Shift+V / Shift+Insert (`terminal.paste`) — вставка локального буфера
  в любой терминал, включая plain shell (где Ctrl+V не пастит по дизайну).
- Копирование мышью/ Ctrl+Shift+C в App кладёт выделение в локальный буфер;
  копирование удалённой программой (xclip) приезжает в Windows через мост.

## Грабли, которые учтены

- cp1251 в subprocess → везде UTF-8 (иначе кириллица роняет синк).
- `\r\n`-накопление при round-trip → нормализация перевода строк.
- xclip -i держит унаследованные fd → запись через временный файл.
- `xclip -o` при image-only буфере отдаёт байты PNG как текст → разбор TARGETS.
- Пустой/недоступный remote не должен затирать локальный буфер (None-skip).
